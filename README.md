# 📄 AI Resume Analyzer

AI-powered Resume Analyzer that checks ATS score & matches job description.

## 🚀 Features
- Upload Resume - PDF / DOCX
- Extract Skills & Experience
- ATS Score Calculation
- Job Description Matching
- Missing Skills Suggestion

## 🛠️ Tech Stack
- Python
- Flask
- NLP - Spacy / NLTK
- PDF Parser
- HTML / CSS

## 📦 How to Run
```bash
pip install -r requirements.txt
python app.py
